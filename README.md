## 📌 Overview

**Know Your Agent (KYA)** is the foundational trust, identity, and authorization infrastructure layer designed for autonomous AI agents operating on financial payment rails (e.g. M-Pesa, stablecoin escrows, and credit underwriting). 

As AI agents perform higher-value autonomous transactions, existing KYC/KYB protocols fail because they assume a human principal at execution time. KYA bridges this gap by issuing **W3C Decentralized Identifiers (DIDs)** and **Verifiable Credentials (VCs)** that define strict spending mandates, single-transaction caps, merchant category restrictions, and real-time **Hardware Security Module (HSM)** prompt injection defense.

---

## ✨ Features

- **W3C Decentralized Identifier (DID) Registry**: Assigns cryptographic DIDs (`did:kya:solana:...`) linked to legal human principals.
- **Verifiable Credential (VC) Mandate Engine**: Encapsulates spending limits, daily caps, allowed merchant categories, and expiration dates in JSON-LD W3C standard credentials.
- **Sherlock Prompt Injection Firewall**: Real-time semantic scanner that intercepts adversarial prompt hijacking vectors (system instruction overrides, wallet drain attempts, cap breaches) before transaction signatures are generated by the HSM.
- **W3C Proof Verifier Playground**: Interactive verification tool that checks Ed25519 cryptographic signatures, DID authority trust roots, and revocation status.
- **Central Bank Regulatory Compliance Console**: Printable regulatory compliance certificates and 1-click JSON/CSV export of cryptographic audit logs.
- **Cyberpunk Audio Alerts**: Real-time Web Audio sound synthesizer for approved payments vs. blocked security threats.

## 🚀 Quick Start

### Running Locally

No complex build pipeline required! Run with any static HTTP server.

```bash
# Clone repository
git clone https://github.com/sandafee/ai-agent.git
cd ai-agent

# Serve using http-server or Python
npx http-server . -p 8085

# Or using Python:
python -m http.server 8085
```

Open your browser at `http://localhost:8085`.
